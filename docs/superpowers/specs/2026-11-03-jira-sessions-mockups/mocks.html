Every strip a card can carry

What the strip says comes from the dashboard's session status (working · question · idle · incomplete) plus what the session is waiting on (question, permission, plan). Ended means the session detached from the ticket and lives on in its history.

Open rules drawn above

  • Primary button follows the surface: launched in the desktop app → Open in Desktop first; launched in the dashboard → Dashboard first.
  • Desktop is greyed while a dashboard-run session is working. claude://resume would start a second process on the same transcript.
  • Rail badge on the Jira row counts Needs you sessions only, never working ones.
  • History is ours: saved on this machine and never written to Jira.
