Link rules

  1. A session links to a ticket three ways: Run ▾ on this board, a branch named for the key, or /jira link inside the session.
  2. The link is saved on this machine, survives a server restart, and is never written to Jira.
  3. A ticket can have several live sessions; every ended one stays as history.
  4. A finished session detaches; the next Run (plan, then execute) takes over.
  5. Open in Dashboard is always offered. Open in Desktop is greyed while a Dashboard-run session is still running, waits included.
  6. The primary button follows the surface the session was started on.
  7. The Jira rail badge counts only sessions that need you.
  8. The board shows the whole picked Jira board, tickets with no agent included.
