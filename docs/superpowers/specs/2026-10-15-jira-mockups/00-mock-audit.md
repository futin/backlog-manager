The canvas is https://claude.ai/artifact/JHdzBd5RCpWWSJwjKNFHZL (version 8). The HTML files beside this one are the PICKED artboards, copied out of the canvas
with the canvas runtime stripped, so they render standalone (approximately — the canvas's `support.js` is not here). `jira.css` is the mocks' own daylight

(tiles-as-boards with the query editor at the bottom; "nothing is clear"). Both stay on the canvas for the record.

the spec overrides a mock.

## Omissions the mocks left open, and the answer the spec gives

- **Phone width** — board columns follow the existing < 700 px rules; Setup's two columns stack; every popover takes `Popover`'s narrow shape.
- **Unconfigured / empty states** — no rail entry at all without `.env` credentials; a configured site with no boards shows `No boards yet` and a chip to Setup;
  a board with no issues draws its three empty columns.
- **Filters popover contents** — type, assignee (anyone / me / unassigned), sprint, derived from the loaded list, per browser, never persisted.
- **Error rows** — a query or root that failed in the last sweep is red in the Band's sub-line and in Setup's board row, with Jira's own message.
- **Stop confirm** — `ui/Confirm`.
- **How long Done stays** — a done-category issue leaves 14 days after its resolution (or, lacking one, its last update), a constant.
- **Attachments and mentions in a description** — ADF → Markdown on the server; a mention becomes `@name`, media and tables become one-line placeholders, and a
  description that had any ends with the open-in-Jira link.
