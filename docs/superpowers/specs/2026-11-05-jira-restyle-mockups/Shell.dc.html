Jira setup
Rail counts share one shape: a plain pill with a number, amber only when something waits on you (2 PRs need you), grey otherwise (1 live Jira session, 3 live runs). The current page is a white row, not a dot. Sync now asks the poller for one sweep at once, for every board or one; it needs a new server route, since today the poller only runs on its 15 s timer.

Why one pill: the poll age and the API budget are numbers you look up, not glance at. The pill keeps the one glanceable fact, connected or not, and how fresh. It turns amber when the poll is late and red when the service is down.
