The same PRs as the Inbox, in the page's two other layouts. Matrix keeps one row per PR and one column per fact, so "what is red" reads down a column; colour marks a problem only, and each header counts its bad rows. Cards groups the PRs by repository. Both reuse the Inbox's status tile, pills and split Merge, so a PR looks the same in every layout.
