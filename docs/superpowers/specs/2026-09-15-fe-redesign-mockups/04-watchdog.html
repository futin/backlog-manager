  • Band subtitle is stateLine verbatim — armed — watching <ids>, next check in Ns, idle — no running run, off — <reason>, each with · resume disabled appended when the switch is off. Off hides the Watching sheet and reads — / nothing is watched while off in the tile; the sweep meter draws only while armed.
  • Watching tile line is today's: N crashed (⚠ when > 0) · N fresh · N not yet watched when the runs payload is a tick ahead of the sweeper.
  • Watching row = the run's project, id, skew note, verdict (● ok / ⚠ crashed), last reported <id> · <stage> or between items, the heartbeat meter (age against RUN_STALE_MS, amber once past it) with its two labels; a crashed row adds attempts dots, the watchdogClause sentence, → session <id> and leave alone Nm more while in grace. The row opens the run: it jumps to History and selects it there, which is what the app already does and what option D keeps — there is no run modal.
  • Resume now is drawn only when watchdogStoodDown — exhausted or switched off — and never while the sweeper still has attempts, whatever the grace clock says. Same gate, same one function, as the Runs live row and its detail sheet.
  • Orphan line: a watched id with no run in the payload, rendered rather than hidden. Empty sheet reads no running run (idle) or nothing running in the runs payload yet (armed).
  • Activity keeps its five columns and full run ids; kinds are the seven of WATCHDOG_KIND_GLYPH, toned by WATCHDOG_KIND_TONE. Empty reads nothing since the server started. The unreachable-API state (Could not reach the watchdog — …) replaces the whole page below the band.

Policy stays in Settings. Runs has no sub-nav.
